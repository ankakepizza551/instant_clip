# InstantClip

ホットキー一発で「直前 N 秒」の画面を mp4 に保存する常駐ツールです。  
NVIDIA ShadowPlay の Instant Replay / OBS のリプレイバッファと同様の動作です。

## 機能

- **リプレイバッファ**: 常時、直近 N 秒（3〜120秒、設定可能）をメモリ／一時ファイルに保持
- **ホットキー保存**: デフォルト **Ctrl+F9** でクリップを `clip_YYYYMMDD_HHMMSS.mp4` として保存
- **キャプチャモード**
  - **自動**: 天則 (th123) 起動中はゲームウィンドウ、未起動時はフルスクリーン（起動・終了に数秒で追従）
  - **フルスクリーン**: 「モニタ」で選んだ画面（メイン / 個別 / すべて）
  - **ゲームウィンドウ**: th123.exe のクライアント領域
- **音声録音**: 選んだ出力デバイスのループバックを録音。VB-Cable を選ぶと通話音などを分けられます
- **切り抜き**: 保存したクリップをプレビューしながらトリミング
- **保存の通知**: 保存できたか／失敗したかを音またはトレイ通知で知らせます
- **自動起動**: Windows ログオン時にトレイ常駐で開始（タスクスケジューラに登録）
- **exe 配布**: PyInstaller でビルド可能

## 必要なもの

- Windows 10 / 11
- Python 3.11+（開発時）
- **ffmpeg.exe** → `ffmpeg/ffmpeg.exe` に配置
- ゲーム音のみを使う場合: [VB-Cable](https://vb-audio.com/Cable/) のインストール

### FFmpeg のセットアップ

1. https://github.com/BtbN/FFmpeg-Builds/releases から `ffmpeg-master-latest-win64-gpl.zip`
2. 解凍して `bin/ffmpeg.exe` を `instant_clip/ffmpeg/ffmpeg.exe` にコピー

`tensoku_rep_movier/ffmpeg/ffmpeg.exe` があればビルド時に自動コピーされます。

## インストール（開発）

```powershell
cd instant_clip
pip install -r requirements.txt
python main.py
```

## 使い方

1. 起動するとバックグラウンドでバッファが自動開始します
2. プレイ中に **Ctrl+F9**（または設定したキー）を押す
3. 出力フォルダに直前 N 秒のクリップが保存されます（デフォルト: `Videos/InstantClip`）

ウィンドウを閉じるとタスクバー通知領域に常駐します（トレイアイコンから復帰・終了）。

## ゲーム音のみの設定

### 方法 A: 自動ルーティング（推奨）

1. VB-Cable をインストール
2. 音声デバイスで **CABLE Input** を選び、「VB-Cable: ゲーム起動時に自動切替」をオン
3. 天則を起動すると Windows の既定の出力が VB-Cable に切り替わり、終了時（ツール終了時も）に元へ戻ります
4. 録音は VB-Cable のループバックから取得

切替中は「既定のデバイス」に出力している他のアプリの音も VB-Cable に流れます。
通話音を混ぜたくない場合は、Discord 等の出力先をヘッドホンなどへ明示的に指定してください。

### 方法 B: 手動

天則の音声設定で出力デバイスを **CABLE Input** に指定してください。

## 設定項目

| 項目 | 説明 | デフォルト |
|------|------|-----------|
| バッファ秒数 | 保持する過去の長さ | 10 |
| ホットキー | 欄をクリックして使いたいキーを押す（文字キーは Ctrl / Alt / Shift と組み合わせ。登録できない時は自動で代替キーに変更） | Ctrl+F9 |
| キャプチャ | auto / fullscreen / game_window | auto |
| モニタ | フルスクリーン録画で撮る画面 | メインモニタ |
| 出力フォルダ | クリップ保存先 | Videos/InstantClip |
| FPS | 録画フレームレート | 30 |
| 画質 | 数値が小さいほど高画質・大容量（crf 相当） | 標準 (23) |
| CPU エンコード | GPU エンコードが使えない時の libx264 プリセット | 最軽量 (ultrafast) |
| 保存の通知 | 音 / トレイ通知 / なし | 音 |
| Windows 起動時に開始 | ログオン時にトレイ常駐で起動 | オフ |
| 音声デバイス | 録音するループバックデバイス（なし = 音声なし） | 既定の出力デバイス |
| 自動ルーティング | ゲーム起動検出で VB-Cable 切替 | オン |

設定は `%APPDATA%\InstantClip\config.json` に保存されます（exe を更新・再ビルドしても引き継がれます）。

## 注意

- 常時キャプチャのため CPU/GPU に負荷がかかります（NVENC 利用時は軽減）
- 天則が管理者権限で動いている場合、本ツールも管理者で起動が必要です（ビルド exe は UAC 管理者昇格）
- gdigrab は一部フルスクリーン DirectX タイトルで黒画面になることがあります
- バッファ開始直後は秒数が足りず保存できない場合があります
- キャプチャ対象の解像度が切り替わった直後（ゲーム起動直後など）は、切替後の映像だけが保存されます
- 通知音は既定の出力デバイスで鳴るため、そのデバイスを録音している場合は次のクリップに入ることがあります。気になる場合は「トレイ通知」か「なし」にしてください
- 自動起動の登録・解除には管理者権限が必要です（ビルドした exe から設定してください）。exe を別のフォルダへ移動した場合は、登録し直してください
- 二重起動はできません（起動済みの場合はトレイから表示してください）
- 録音した音声が無音だった場合は、ログに警告が出ます（音声デバイスの選択を確認してください）
- 選んだ音声デバイスが見つからない場合は、他のデバイスで代用せず音声なしで録画します
