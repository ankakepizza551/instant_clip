========================================
  InstantClip — 直前クリップ保存ツール
========================================

◆ 概要
  常時バッファし、ホットキー (既定 F9) で直前 N 秒を mp4 保存します。

◆ 起動
  InstantClip.exe をダブルクリック

◆ ゲーム音のみ
  VB-Cable が必要です。
  設定で「ゲーム音のみ」「自動切替」をオンにし、
  ツール起動後に天則を起動してください。

◆ 出力先
  既定: 動画\InstantClip\clip_日時.mp4

◆ FFmpeg
  ffmpeg\ffmpeg.exe が同梱されている必要があります。
